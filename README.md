# EmoTrack

🏆 1st place, CodeBrew 2023 (24-hour hackathon).

EmoTrack is a parent-facing site helping parents recognise and respond to their children's emotional wellbeing and mental health signals, drawing on guidance from the CDC, APA, and Healthdirect. Built with WordPress and JotForm.

See `Resources/` for reference material used while building it, and `EmoTrack.mp4` for a demo recording.
